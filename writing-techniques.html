1 ．はじめに

「南都六宗 - 三論宗、成実宗、倶舎宗、法相宗、華厳宗、律宗。だがこの『六宗』、実は現代人がそのまま鵜呑みにすると足をすくわれる言葉なのだ。」

これは、以前に書いた南都六宗についての記事 [27] の冒頭近くにある一節である。固有名詞を六つ並べたあとに、それを軽く裏切る一文を置く。この一文だけを読んでも、多くの人は「え、どういうこと」と先を読みたくなるはずだ。

それは偶然ではない。あの記事を書いたとき、いくつかの技法を意識的に使っていた。固有名詞を列挙してリズムを作り、そのリズムを裏切る文で読者の注意を引く。要所には、本文から一文を抜き出して大きく見せる「プルクオート」を置く。段落の長さを操作して、読むテンポそのものをコントロールする。

これらの技法について「何か体系立った理論として知られているものか」と考えたところから、この記事は始まった。調べてみると、答えは「はい、ただし一つの理論ではない」だった。文章を魅力的にする技法は、修辞学、心理学、物語論、ジャーナリズム、コピーライティング、そして誌面設計（エディトリアルデザイン）という、まったく別々の分野でそれぞれ独立に発見され、名付けられてきたものの集合なのである。

文章を魅力的にする技法は、一つの理論ではない。別々の分野で、別々の人が、別々の理由から発見してきた技法の寄せ集めである。

この記事は、その寄せ集めを一望できるカタログとしてまとめたものだ。学術的な考察が目的ではない。技法ごとに「何をする技法か」「なぜ効くとされるのか」「具体例」「使う上での注意点」を並べ、そのまま自分の文章に応用できる粒度に落とし込むことを目指す。理論的背景は、使いこなすために必要な最小限だけ添える。

2 ．修辞学（レトリック）の技法

古代ギリシア・ローマの弁論術に起源を持つ、文の「構文」そのものでリズムと説得力を作る技法群。二千年以上前に体系化されたにもかかわらず、現代の演説やキャッチコピーでも変わらず使われている。

列挙法・首句反復（enumeratio/anaphora）

修辞学

定義 : 同種の語や事物を連続して並べる「列挙法」と、複数の文・節の冒頭を同じ語句で揃える「首句反復」。しばしば組み合わせて使われ、同じ構文の反復で読者に一定の「拍」を刻ませる。

なぜ効くのか : 反復は予測可能なリズムを作る。人はリズムに乗ると読み進めやすくなり、逆にそのリズムが破られた瞬間（反復が途切れる、意外な結論が来る）に注意が跳ね上がる。反復そのものより、反復を作ってから崩す構成が効果を生む。

具体例 : 「東大寺の大仏殿。興福寺の五重塔。薬師寺の東塔。唐招提寺の金堂。」 - 固有名詞を同じ構文で四つ並べたあと、「どれも『古い寺』と紹介される。だが、よく考えると、この言い方自体が謎めいている。」と展開を裏切る [27] 。

注意点・乱用のリスク : 反復を裏切らずに終えると、単なる箇条書きの羅列に見えてしまう。列挙は「その先に何かがある」という予感とセットで使う。

トライコロン（tricolon ・三段法）

修辞学

定義 : 三つの語・句・節を並列させる技法。ギリシア語の「三（tria）」と「節（kōlon）」に由来する。二つでは物足りず、四つでは冗長になる - 三という数がリズムとして最も収まりが良いとされる [1] 。

なぜ効くのか : 「三つ組の法則」は記憶にも残りやすく、完結感を生みやすいと言われる。古代ローマの弁論家キケロが多用したことで知られ、「来た、見た、勝った（Veni, vidi, vici）」はカエサルの言葉として伝わる典型例である [2] 。

具体例 : 「経典が受け渡され続け、儀礼が絶えず、伽藍は焼けるたびに立ち上がり直してきた。」 - 三つの動詞句を並べることで、単発の事実ではなく「継続してきた総体」であることを印象づける。

注意点・乱用のリスク : 毎段落で三段法を使うと、文体が作為的で単調に見える。ここぞという要所に絞って使う。

アンチテーゼ（対句・対比）

修辞学

定義 : 対立する語や句を、均整の取れた構文の中で並べる技法。アリストテレスは、対比によって主張の論点が理解しやすくなると指摘している [3] 。

なぜ効くのか : 対比構文は差分を際立たせる。二つの事物を並べて見せるだけで、読者は自分で「何が違うのか」を発見した感覚を持ちやすい。説明するより、対比させて気づかせるほうが記憶に残る [4] 。

具体例 : 「変わらなかったから、ではない。変わり続けながら、残すべきものを選び続けたからだ。」 - 否定形と肯定形を対にすることで、読者の予想（「変わらなかったから長持ちした」）をまず提示し、それを覆す。

注意点・乱用のリスク : 対比の両辺が本当に対になっていないと（語調は対句なのに中身が対応していないと）、読者にはむしろ違和感として伝わる。

エピストロフィ（文末反復）

修辞学

定義 : 首句反復（anaphora）の対になる技法で、連続する文や節を同じ語句で終える [5] 。文頭ではなく文末を揃えることで、結論部分を強調する効果がある。

なぜ効くのか : 文末は読者の記憶に残りやすい位置（新近性効果）であるため、そこを反復語で固定すると、その語がテーマとして刷り込まれやすい。

具体例 : 「檀家がいる。葬儀をする。墓を管理する。法事をする。」 - 文末を「〜する」で統一し、寺に対する紋切り型のイメージをリズムよく列挙してから、次段でそれを相対化する構成に使える。

注意点・乱用のリスク : 首句反復より使用頻度は低く、多用すると説教くさい印象になりやすい。宣言・結論部に絞って使うと効果的。

3 ．読者を引き込む心理学の技法

なぜ人はある構成にだけ引き込まれるのか。この問いに答えを与えるのが、認知心理学や行動経済学の知見である。修辞学が「どう組み立てるか」の技法だとすれば、こちらは「なぜそれが効くのか」のメカニズムに近い。

curiosity gap （好奇心の間隙）

心理学

定義 : 「知っていること」と「知りたいこと」のあいだに隙間があるとき、人はその隙間を埋めたいという欲求を抱く。カーネギーメロン大学の行動経済学者 George Loewenstein が 1994 年の論文で定式化した「情報ギャップ理論」に基づく [8][9] 。

なぜ効くのか : Loewenstein の理論では、好奇心は「自分の知識に空白があると気づいた瞬間」に生じる、一種の不快な欠乏状態として説明される。人はその不快感を解消するために、続きを読む・調べるという行動を取る。

具体例 : 「千三百年、何を残し、何を作り直してきたか」という見出しは、「何を残し、何を作り直してきたのか」という空白を読者の中に作る。答えは本文まで明かされない。

注意点・乱用のリスク : いわゆる「釣りタイトル」の多くはこの理論の悪用例である。空白を作っても、本文がその空白を誠実に埋めなければ、読者の不快感は解消されず不信感に変わる。

オープンループ／ミニクリフハンガー

心理学／物語論

定義 : 物語やコンテンツの中に、あえて未解決のまま残す問い・伏線を仕込み、それを先送りにし続ける技法。 curiosity gap を文章全体の設計原理にまで拡張したもの、と捉えることができる。

なぜ効くのか : 一つの問いに答えると同時に、次の小さな問いを提示する。この「答え→新しい問い」の連鎖が、読者を段落から段落へと運ぶ推進力になる。理論的な裏付けは curiosity gap と共通する [8] 。

具体例 : 「では、どうしたか。作り直したのだ。しかも 20 世紀後半、驚くほどユニークな方法で。」 - 一つの謎（伽藍消失）への答えを匂わせつつ、「ユニークな方法」という新しい謎を即座に提示している。

注意点・乱用のリスク : 実用記事でオープンループを多用しすぎると、読者が「早く結論を教えてほしい」と感じて離脱する。実践ガイドでは節ごとに一つ程度に抑えるのが安全。

チェーホフの銃

物語論

定義 : 「物語の序盤に提示した要素は、後で必ず意味を持たせなければならない」という創作上の原則。ロシアの劇作家アントン・チェーホフが 1889 年の手紙の中で述べた比喩に由来する。「第一幕で壁に銃が掛かっているなら、それは後の幕で発砲されなければならない」 [10][11] 。

なぜ効くのか : 読者は提示された情報を無意識に「伏線」として保持する。それが後で回収されると満足感が生まれ、逆に回収されないと（あるいは無関係な要素が多すぎると）物語の焦点がぼやける。

具体例 : 実践ガイドの文脈では、「冒頭で提示した謎かけには、必ず本文中で答えを用意する」という運用に読み替えられる。 curiosity gap で開けた空白を放置しないための、いわば品質管理の原則。

注意点・乱用のリスク : 厳密に適用しすぎると、雑談的な余談やディテールを一切書けなくなる。実用文では「読者の記憶に残る規模の伏線」に限定して適用するのが現実的。

4 ．物語構造の技法

一文・一段落単位の技法ではなく、記事全体の設計図に関わる技法。ノンフィクションや実用記事であっても、物語構造を借りると読者の体感的な「流れ」が生まれる。

三幕構成

物語論

定義 : 物語を「設定（Setup）」「対立・展開（Confrontation）」「解決（Resolution）」の三つに分ける構成法。起源はアリストテレス『詩学』の「始まり・中間・終わり」に遡るとされ、現代的な脚本術としては、脚本家 Syd Field が 1979 年の著書 Screenplay で定式化した [6][7] 。

なぜ効くのか : 読者は「前提の提示 → 前提が揺さぶられる → 新しい理解に着地する」という流れに、心理的な満足を感じやすい。実用記事に応用すると、「常識の提示 → その常識のほころびを見せる → 新しい見方を提案する」という型になる。

具体例 : 南都六宗の記事は、「古い寺として紹介される（設定）」→「『六宗』という言葉自体が実は誤解を招く、宗派が次々現れても奈良仏教は消えなかった（対立・展開）」→「長寿の秘密は変わらないことではなく、変わり続けたことだった（解決）」という三幕構成を取っている。

注意点・乱用のリスク : 短い記事に無理に三幕を当てはめると、各幕が薄くなる。文字数が少ない場合は、次に述べる「抽象→具体→抽象」のようなもっと軽い構造で十分なことも多い。

抽象 → 具体 → 抽象の往復

文章作法

定義 : 一般論やテーゼを提示し、それを裏付ける個別のエピソード・データに降り、再び一般論へ戻って結論づける、という上下運動を繰り返す構成法。三幕構成をより小さな単位（段落〜節）で繰り返し適用したものと言える。

なぜ効くのか : 抽象論だけでは実感が湧かず、具体例だけでは「で、結局何が言いたいのか」が見えなくなる。往復させることで、主張の説得力と実感の両方を確保できる。

具体例 : 南都六宗の記事は「寺院は巨大な記憶装置だった（抽象）」→「薬師寺の伽藍が焼失し、写経勧進によって再建された（具体）」→「昭和・平成・令和の人々が古代の遺産を自分たちの時代にもう一度引き受けた（抽象への回帰）」という往復を、章の中で、あるいは章をまたいで繰り返している。

注意点・乱用のリスク : 往復の幅が狭すぎる（抽象と具体がほぼ同じことを言い換えているだけ）と、単なる冗長な文章になる。具体例は、抽象論からは予想できないディテールを含んでいるほうが良い。

5 ．リード文（書き出し）の型 - ジャーナリズムの技法

記事の最初の数行は、読み進めるかどうかを決める最大の分岐点である。新聞・雑誌ジャーナリズムは、この書き出しの型を長年かけて洗練させてきた。

逆三角形・サマリーリード

ジャーナリズム

定義 : 最も重要な事実（結論）を冒頭に置き、以下は重要度の低い情報へと下っていく構成。 1865 年のリンカーン暗殺を伝えた AP 通信の記事が初期の代表例とされ、その後 AP をはじめとする通信社の標準スタイルとして定着した [12][13] 。

なぜ効くのか : 読者がどこで読むのをやめても、最も重要な情報だけは受け取れる。電信のコストが高かった時代や、紙面編集で記事の下部から機械的に削られる時代の実務的要請から生まれたとされるが、現代の「流し読み」する読者にも合致する。

具体例 : この記事自体、導入の直後に「文章を魅力的にする技法は、一つの理論ではない」という結論を先に置いている。詳細（各技法）はそのあとに続く。

注意点・乱用のリスク : 結論を先出しすることで、 curiosity gap （空白を作って引き込む）の効果とは方向性が逆になる。どちらを使うかは、読者に「先に安心してほしい記事」か「引っ張って読ませたい記事」かで使い分ける。

アネクドート（逸話）リード

ジャーナリズム

定義 : 結論やテーマをいきなり述べるのではなく、具体的な一場面・一人物のエピソードから書き始め、そこから徐々に主題へと視野を広げていく書き出しの型 [14][15] 。

なぜ効くのか : 人間は抽象的な統計やテーゼより、具体的な人物や場面の描写に感情移入しやすい。逆三角形が「情報の効率」を優先する型だとすれば、アネクドートリードは「読者の感情的な没入」を優先する型である。

具体例 : 南都六宗の記事は「奈良で大寺院を歩くと、少し奇妙な感覚に襲われる」という、書き手自身の体感から始まる。統計や定義からではなく、感覚の描写から入っている。

注意点・乱用のリスク : エピソードが長すぎると、本題になかなか入らず読者が離脱する。逸話は「本題への入り口」であって、本題そのものではないことを忘れない。

6 ．コピーライティングのフレームワーク

広告・セールスライティングの世界で発展した、読者の行動を最終的な一歩（購入・登録・共感）まで導くための構成フレームワーク。実用記事でも「最後まで読ませ、行動につなげる」目的があるなら応用できる。

AIDA

コピーライティング

定義 : Attention （注意）→ Interest （興味）→ Desire （欲求）→ Action （行動）の頭文字を取ったフレームワーク。広告業界の先駆者 Elias St. Elmo Lewis が 1898 年頃に Attention → Interest → Desire の枠組みを提唱し、後年 Action が加わって現在の形になったとされる。 1920 年代には心理学者 Edward K. Strong がこの枠組みをさらに精緻化している [16][17] 。

なぜ効くのか : 読者の心理状態は一様ではなく、段階的に変化する。注意を引く前にいきなり行動を求めても響かない、という前提に立ち、四段階を順番に踏ませることで離脱を減らす。

具体例 : 見出しで注意を引き（Attention）、 curiosity gap で興味を持続させ（Interest）、具体例やベネフィットで「自分にも使えそうだ」という欲求を作り（Desire）、実践チェックリストで行動を促す（Action）- この記事自体がおおむねこの型をなぞっている。

注意点・乱用のリスク : 四段階を機械的に当てはめると広告臭さが出やすい。特に情報記事・エッセイでは Action を露骨にしすぎない配慮が要る。

PAS (Problem - Agitate - Solve)

コピーライティング

定義 : Problem （問題を提示する）→ Agitate （その問題を掘り下げ、痛みを強調する）→ Solve （解決策を示す）という三段階の構成。ダイレクトレスポンス広告の実務の中で発展してきた技法とされ、コピーライター Gary Bencivenga の名がしばしば挙げられるが、起源については諸説あり断定はできない [18] 。

なぜ効くのか : 問題を提示しただけでは、読者は「まあ大した問題ではない」と読み流してしまう。あえて問題を掘り下げて実感させてから解決策を示すことで、解決策のありがたみが増す。

具体例 : 「技法はバラバラに存在し、体系だって学ぶ機会がない（Problem）」「だから多くの書き手は、なぜ自分の文章が読まれないのか分からないまま書き続けている（Agitate）」「この記事はその技法を一望できるカタログとして整理する（Solve）」という流れに読み替えられる。

注意点・乱用のリスク : Agitate （問題の掘り下げ）を煽情的にやりすぎると、不安を煽るだけの文章になりかねない。実用ガイドでは Agitate を「共感」程度に抑えるのが穏当。

7 ．文章そのもののテンポと可読性

構成の技法とは別に、一文一文の長さ・難易度そのものが読みやすさを左右する。こちらは経験則と、それを裏付ける計量的な指標の両方が存在する。

文長によるテンポ制御

文章読本・作文技術

定義 : 文の長さを意図的に変化させることで、読むスピードや緊張感をコントロールする技法。本多勝一は著書『日本語の作文技術』の中で、修飾語の順序や句読点の打ち方など、読みやすい文の技術的な条件を具体的に論じている。英語圏では William Zinsser が On Writing Well の中で、簡潔さこそが良い文章の条件であると繰り返し説いている。

なぜ効くのか : 短文の連続は読むスピードを上げ、緊張感や躍動感を生む。長文は情報を丁寧に積み重ね、落ち着いた説明のトーンを作る。同じ長さの文が延々と続くと、内容にかかわらず単調に感じられてしまう。

具体例 : 「大仏が造られた。寺が栄えた。時代が変わった。戦乱が起きた。」 - 短文を連ねることで、長い年月の出来事を畳みかけるように提示し、読者に「時間の重み」を体感させている。

注意点・乱用のリスク : 短文を延々と続けると、逆に幼稚な印象や息切れした印象を与える。テンポを作りたい要所にだけ集中して使うのが効果的。

可読性指標（Flesch-Kincaid / 日本語の指標）

計量的指標

定義 : 英語圏では、文の平均語数・単語の平均音節数から読みやすさを数値化する Flesch Reading Ease 、および学年レベルに換算する Flesch-Kincaid Grade Level が広く使われている。 Rudolf Flesch が 1940 年代から開発を進め、 1975 年に心理学者 J. Peter Kincaid が米海軍向けにグレードレベル版を確立した [19] 。日本語では、文の長さや語彙の難易度などから読みやすさを推定する「 jReadability 」が、李在鎬らの研究に基づき公開されている [20][21] 。

なぜ効くのか : 感覚的な「読みやすさ」を数値化することで、自分の文章の癖（一文が長すぎる、専門用語が多すぎる等）を客観的にチェックできる。あくまで補助的な指標であり、これ自体が良い文章を保証するものではない。

具体例 : 実用記事を書いたあと、 jReadability のようなツールに通し、平均文長や語彙の難易度が想定読者に見合っているかを確認する、という使い方ができる。

注意点・乱用のリスク : 数値を下げること自体が目的化すると、不自然に単純化された、味気ない文章になる。指標は診断のためのものであり、最終判断は人間の読み手の感覚に委ねるべき。

8 ．エディトリアルデザイン（誌面設計）の技法

最後は、文章そのものではなく、文章の「見せ方」に関わる技法。雑誌・新聞編集の現場で培われてきたレイアウトの工夫であり、文章構成論とは別のレイヤーに属する。

プルクオート

エディトリアルデザイン

定義 : 本文中の一文を抜き出し、大きな文字で強調表示するレイアウト要素。文章構成論というより、雑誌・新聞編集の用語である [23] 。

なぜ効くのか : 二つの役割がある。一つは視覚的な休符を作ること（長い本文の合間に、目を休める余白と強調点を作る）。もう一つはスキャン読みへの対応（記事を最初から読まない読者に、要点を先に見せる）。

具体例 : この記事自体、各節の要所に「文章を魅力的にする技法は、一つの理論ではない」のようなプルクオートを配置している。

注意点・乱用のリスク : 本文の要約になっていない、あるいは単に目立つだけの一文を抜き出すと、記事のトーンと浮いて見える。プルクオートに向くのは、その節の主張が凝縮された一文。

サイドバー・囲み記事・キャプション

エディトリアルデザイン

定義 : 本文の流れを止めずに、補足情報（用語解説、関連データ、余談）を別枠として配置するレイアウト要素。雑誌のグリッドデザインにおける基本パーツの一つとされる [22] 。

なぜ効くのか : 本文の主線を「太い一本の流れ」として保ちながら、興味のある読者だけが寄り道できる補助線を用意できる。本文に補足を書き込むと文章のテンポが崩れるが、別枠にすれば両立できる。

具体例 : この記事における「注意点・乱用のリスク」ボックスや「具体例」ボックスは、囲み記事の考え方をウェブ上のカード型レイアウトに翻訳したものである。

注意点・乱用のリスク : 囲み記事を増やしすぎると、どれが本筋でどれが補足か読者に伝わらなくなる。本文と視覚的に明確に区別すること（枠線、背景色、フォントの違いなど）が前提になる。

見出し設計とスキャン読み

エディトリアルデザイン

定義 : 読者が本文を上から順に読むのではなく、見出しや太字だけを拾い読み（スキャン読み）する前提でコンテンツを設計する考え方。ウェブユーザビリティ研究者 Jakob Nielsen らのアイトラッキング調査は、読者がウェブページを「 F 字型」の視線パターンで読む傾向を示した [26] 。

なぜ効くのか : 見出しだけを読んでも記事の骨子が伝わるように設計しておけば、精読する読者にもスキャン読みする読者にも対応できる。目次（この記事冒頭のもの）も、スキャン読みへの対応の一形態である。

具体例 : この記事の見出しは「◯◯とは」ではなく、なるべく技法名そのものを名詞で置き、小見出しの並びだけで全体の地図が見えるように統一している。

注意点・乱用のリスク : 見出しを凝りすぎて内容を表さない（いわゆる「うまい見出し」優先）にすると、スキャン読みする読者には逆に何の記事か伝わらなくなる。

9 ．技法同士の関係を整理する

ここまで 18 の技法を並べたが、これらは決して同じレイヤーにある技法ではない。混同すると「なぜこの技法を使うのか」の説明がぶれてしまうので、いったん整理しておく。

レイヤー 扱う対象 代表的な技法
文の構文（レトリック） 一文・一節の組み立て方 列挙法・トライコロン・アンチテーゼ・エピストロフィ
読者の心理メカニズム なぜ引き込まれるかの説明原理 curiosity gap ・オープンループ
記事全体の設計図 導入から結論までの流れ 三幕構成・抽象具体の往復・チェーホフの銃
書き出しの型 最初の数行の作り方 逆三角形・アネクドートリード
行動喚起の設計 読者を最後まで運び、行動させる AIDA ・ PAS
文そのものの質感 読みやすさ・テンポの計量 文長制御・可読性指標
見せ方（レイアウト） 文章とは別の視覚的工夫 プルクオート・囲み記事・見出し設計

重要なのは、これらのレイヤーは互いに排他的ではなく、同時に重ねて使えるという点だ。たとえば curiosity gap で読者の興味を引きつけながら（心理）、三幕構成で記事全体を組み立て（構造）、要所にプルクオートを置く（見せ方） - 一つの記事の中で、複数のレイヤーの技法が同時並行で働いている。逆に言えば、「なぜかうまく読ませる記事」を分解すると、たいてい複数のレイヤーの技法が重なっていることが多い。

技法は一つずつ効くのではなく、レイヤーの異なる技法を重ねたときに、初めて「読まされてしまう文章」になる。

10 ．実践チェックリスト

書き終えたら、あるいは書く前の設計段階で、以下を確認してみてほしい。すべてを満たす必要はないが、多く当てはまるほど「読まされる」文章に近づく。

  • 書き出し : 逆三角形（結論先出し）とアネクドートリード（具体的な場面から）、どちらの型を使うかを意識して選んだか。
  • フック : 冒頭で curiosity gap （答えを知りたくなる空白）を作ったか。作った空白は、本文中で必ず埋めているか（チェーホフの銃）。
  • リズム : 同じ長さの文が単調に続いていないか。緊張感を出したい箇所で短文を、丁寧に説明したい箇所で長文を意図的に使い分けたか。
  • 構文の技法 : ここぞという一文で、トライコロンや対句、反復を使えないか検討したか。
  • 全体構造 : 記事全体、あるいは各節が「前提 → 展開・裏切り → 着地」の流れになっているか。
  • 具体と抽象 : 主張を述べたら具体例に降り、具体例で終わらせず再び主張に戻っているか。
  • 見せ方 : 精読しない読者のために、見出しだけで骨子が伝わるか。要所にプルクオートを置けないか。
  • 可読性 : 専門用語や一文の長さが、想定読者にとって過剰になっていないか。
  • 行動喚起 : この記事を読んだ読者に、次に何をしてほしいのかが明確か（AIDA の Action 、 PAS の Solve に相当）。

11 ．技法は、迷ったときの地図になる

文章の魅力は、最終的には言語化しきれない部分に宿る。だからこの記事に挙げた 18 の技法をすべて満たしても、面白い文章が自動的に書けるわけではない。修辞学は二千年以上前から存在するが、退屈な演説は今もなくならない。

それでも、これらの技法を知っておく価値はある。書いていて「何かが足りない」と感じたとき、あるいは読み返して「なぜかうまく読ませられない」と感じたとき、この記事のカタログは、その違和感の正体を言い当てるための地図になる。書き出しの型が合っていないのか。構文のリズムが単調なのか。空白を作ったのに埋め忘れているのか。地図があれば、迷った場所を指差すことができる。

南都六宗の記事を書いたときは、これらの技法の名前をほとんど意識していなかった。感覚的に「ここは畳みかけたい」「ここで一度立ち止まらせたい」と判断していただけだ。だが、それらの判断には、すでに名前がついていた。技法を知ることの意味は、感覚を置き換えることではなく、すでに使っている感覚に、再現可能な名前を与えることにある。

名前がつけば、次はもっと自覚的に使える。 そして自覚的に使えば、次はもっと外して、もっと組み合わせられる。
