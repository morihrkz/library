コーディング環境 Antigravity 2.0 / Antigravity CLI デスクトップアプリと CLI が同一基盤。 Gemini 3.8 Flash に対応。法人向けは Gemini Code Assist Enterprise （VS Code 、 JetBrains 統合）が継続。 Codex / Codex CLI ChatGPT 、エディタ、ターミナルを横断し、 GPT-6 Astra まで対応。 Claude Code ターミナル中心。 Web 検索、 Git 、 MCP なども利用可能。 Grok Build (TUI)+ Cursor （エディタ）+ Grok Bot （常時稼働クラウド） ターミナル型の Grok Build は ACP により他社エディタ・開発環境との連携も展開。 Cursor は AI を中心に再設計したコードエディタで、 Origin （コードホスティング）は Vercel ・ Depot ・ Buildkite 連携も備える。 SpaceX 傘下で性格の異なる複数のコーディング環境を並行運用する、他社にない構図になっている。 Muse Code / Meta Model API 2026 年 9 月 1 日に正式版へ移行した CLI 中心のエージェント。 Meta Model API （2026 年 7 月 public preview 開始）により Spark を自社 API として提供。 VS Code / JetBrains 拡張は今後拡充予定。

一言で表すなら 「 Google の AI エコシステム」 検索・クラウド・ OS ・ Workspace まで含めた総合型。 「汎用 AI アシスタント +AI エージェント」 ChatGPT を入口に、調査・作業・コーディングまで広げる。 「高性能モデル +AI エージェント」 Claude Code を含む知的作業・開発への深い統合。 「 Grok+Cursor+ 常時稼働エージェント」 基盤モデルからコーディング環境、 24 時間稼働するクラウドエージェントまで、 1 社で垂直統合する戦略。 「配布力 × スーパーインテリジェンス」 30 億人規模のソーシャルグラフに Muse Spark と Muse Code を直接届ける企業。
