# library

AI と共同で執筆した論考を公開する GitHub Pages サイトのリポジトリ。

- 公開 URL: https://morihrkz.github.io/library/
- 公開ブランチ: `main`(ブランチを切らず直接コミットする運用)

## 構成

ビルドツールは使わず、静的 HTML をそのまま GitHub Pages が配信する。

- `index.html` — ポータルページ。7 分野に分類した目次と、各記事へのカードリンクを持つ。
- `*.html`(上記以外) — 個々の論考。すべてルート直下にフラット配置。
- `future-article-themes.md` — 次に書くテーマの検討メモ。既存記事の分類・関心の構造から、まだ手つかずの角度を洗い出したもの。着手・完了のたびに更新する。
- `public_URL.txt` — 公開 URL とリポジトリ URL のメモ(`.gitignore` 対象、リポジトリには含まれない)。

## 記事の分類(7 分野)

`index.html` の目次と対応する。新しい記事を追加する際は、内容に最も近い分野へ収める。

1. 比較政治学・時事分析
2. 心理学
3. 哲学・論理学
4. 自然科学
5. 歴史・宗教・教育
6. テクノロジー・産業分析
7. 社会評論・生き方・文章技法

分類は主観的な整理であり、複数分野にまたがる記事を便宜的に一つの分野へ収めている場合がある(`index.html` 末尾の note を参照)。

## 新規記事を追加する手順

1. 記事の HTML ファイルをリポジトリのルート直下に追加する。
2. `index.html` の該当分野のセクションに、カード(`<a class="card">`)を追加する。
3. `index.html` の以下 3 箇所を更新する。
   - `<title>` 直後の `subtitle`(記事総数)
   - 目次(`<nav class="toc">`)内、該当分野の本数表記
   - 該当分野の `<h2>` 見出しの本数表記
4. 分野の記事構成が変わった場合は、`future-article-themes.md` の該当クラスタの記述も見直す。

## 記事の統合・改題・削除

過去に複数記事を 1 本へ統合した例がある(例: `envy-comparison-theory.html` と `ranking-formation-structure.html` を `social-comparison-theory.html` へ統合)。この場合は、統合元ファイルを削除し、`index.html` のリンク・本数表記・分野説明文を統合後の内容に合わせて更新する。

## 次のテーマを検討する

`future-article-themes.md` に、既存記事の関心構造から見える「まだ書かれていない角度」がクラスタ別に整理されている。新しい記事の着想が必要な際はまずここを参照し、着手・公開したテーマは同ファイルの完了記録に反映する。
