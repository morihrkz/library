# 余白の書庫

哲学・心理・政治・科学・テクノロジーなど、 71 本の論考や入門記事を集めた日本語の読みものサイトです。個々の記事を読むだけでなく、隣り合う問いへ進めるよう、テーマごとに整理したポータルを用意しています。

## 公開ページ

サイトの入口は [`index.html`](index.html) です。八つのテーマから記事を選べます。

| テーマ | 内容 |
| --- | --- |
| 考える技法 | 哲学的思考、推論、因果、論証、言語哲学、文章表現、誤情報と確信の心理 |
| 心と自己 | 判断、集団、比較、後悔、自己理解、動機、承認と趣味、社会心理、心理臨床の制度 |
| 倫理と生き方 | 倫理学、道徳、教養教育、自由意志、幸福、反出生主義 |
| 政治と社会 | 民意、政党、選挙制度の比較、ポピュリズム、トランプ支持の逆説、権威主義、政治心理、永世中立と直接民主主義、試験制度の利害設計 |
| 技術と仕組み | 生成 AI 、クラウド、 SaaS 、インターネット、労働と分配、アルゴリズムの説明責任、日本の工業製品の競争力、テレビ放送方式 |
| 自然科学 | 電池、素粒子、地質時代、宇宙論、老化研究、脳内物質 |
| 歴史と宗教 | 時代区分、仏教、キリスト教、イスラーム |
| 暮らしとケア | 医療、住まい、自立とケアの規範 |

## ローカルで読む

`index.html` をブラウザーで開くと、そのまま閲覧できます。ローカルサーバーを使う場合は、プロジェクトのルートで次のコマンドを実行してください。

```sh
python3 -m http.server 8000
```

ブラウザーで <http://localhost:8000/> を開きます。

## ファイル構成

```text
.
├── index.html       # テーマ別ポータル
├── README.md        # プロジェクトの案内
└── *.html           # 各記事（71本）
```

記事はそれぞれ独立した HTML ファイルです。ポータルから各記事へ相対リンクで移動できます。ビルド工程や外部依存はありません。

## 技術

- HTML と CSS による静的サイト
- ポータルはレスポンシブ対応
- JavaScript 、ビルドツール、外部ライブラリ不要
