## ローカルで読む

`index.html` をブラウザーで開くと、そのまま閲覧できます。ローカルサーバーを使う場合は、プロジェクトのルートで次のコマンドを実行してください。

```sh
python3 -m http.server 8000
```

ブラウザーで <http://localhost:8000/> を開きます。

## ファイル構成

```text
.
├── index.html                # テーマ別ポータル
├── README.md                 # プロジェクトの案内
├── CLAUDE.md                 # 作業指示（記事の意匠は Claude Code のスキルを正とする）
├── future-article-themes.md  # 現状の整理と、次に書く記事のテーマ候補
├── public_URL.txt            # 公開 URL とリポジトリ URL（Git 管理外）
└── *.html                    # 各記事（ index.html を除き 80 本）
```

記事はそれぞれ独立した HTML ファイルです。ポータルから各記事へ相対リンクで移動できます。ビルド工程や外部依存はありません。
