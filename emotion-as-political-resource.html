感情はいかに政治資源化されるか

米国社会の分断と不満のポピュリズム構造 — 「奪われ感」はどこから生まれ、誰によってどう動員されるのか

現代の民主主義国家、なかでも米国の政治を理解しようとするとき、政策論争の表面だけを見ていては本質を見誤る。そこで実際に動員されているのは、政策そのものよりも「自分たちは不当に扱われている」「かつて持っていたものを奪われた」という感情である。この現象は米国に限らない。欧州の右派ポピュリズム政党の台頭、日本における排外的言説の一部にも共通する構造が見られる。本稿は、その中でも特に分析素材が豊富な米国のトランプ支持層における「不公平感」「逆差別感」を主たる事例としながら、感情が政治的資源として動員される一般的なメカニズムと、それに対して民主主義がどう応答しうるかを論じる。

あらかじめ断っておきたいのは、本稿の目的が特定の政治家個人への断罪ではないという点である。ドナルド・トランプという政治家は、以下で論じる「不満の政治資源化」という現象の担い手の一人ではあるが、唯一の原因ではない。彼が退場しても、同じ構造的条件が残っていれば、類似の政治現象は形を変えて再生産されるだろう。焦点を当てるべきは個人の資質ではなく、不満が生成され、それが特定の方向へ流し込まれていく回路そのものである。

トランプ支持層の実相 — 何が「不当さ」の感覚を生むのか

トランプ支持層を一枚岩の集団として語ることはできない。まず押さえておくべき事実は、その支持基盤が近年多様化しているということである。 2024 年米大統領選の出口調査によれば、トランプは 2020 年と比較してヒスパニック系男性の支持を大きく伸ばし、 36% から 53 〜 54% へと拡大した。黒人有権者全体への支持も 8% から 15% へとほぼ倍増し、黒人男性に限れば 20% に達した (2020 年から 1 ポイント増 )[1][2] 。この事実は、支持基盤を「白人男性」という単一属性に還元する図式が、もはや実態を正確に説明していないことを示している。人種的属性よりも、学歴・居住地 ( 都市部か非都市部か ) ・経済的立場といった要因のほうが、支持態度の分岐をより強く説明するという分析枠組みが有力になりつつある。

その上で、トランプ支持層に広く見られる感覚を、少なくとも三つの層に分けて理解する必要がある。

(1) 経済的取り残され感

2000 年代の製造業雇用の急減は、統計的に確認された事実である。経済学者デイヴィッド・オーター、デイヴィッド・ドーン、ゴードン・ハンソンらが 2016 年の論文で提示した「チャイナ・ショック」という分析枠組みによれば、中国の世界貿易機関 (WTO) 加盟 (2001 年 ) 後の対中輸入急増により、 2000 年から 2007 年の間に 150 万〜 200 万人規模の製造業雇用が失われたとされる。これは同期間の製造業雇用減少のおよそ 4 分の 1 に相当するとの推計もある [3] 。ただし、この「チャイナ・ショック」の規模や、それが米国経済全体に与えた影響の評価については、経済学者の間でなお論争が続いており、単一の確定した数値があるわけではない。この点は「学術的に係争中の論点」として扱うべきである。

いずれにせよ、脱工業化によって職と誇りの双方を失ったと感じるラストベルトの労働者にとって、この経験は抽象的な統計以上の意味を持つ。自分たちの生活水準の低下が、グローバル化の恩恵を受けた都市部エリートの繁栄と同時進行しているという対比は、強い不公平感の土壌となる。

(2) 文化・人種的危機感

もう一つの層は、人口構成の変化や、多様性・公正・包摂 (DEI) を掲げる政策・企業文化への反発である。ここで重要なのは、この反発の当事者たちが自らの立場を語るときの言葉を、歪めずに正確に紹介することである。彼らの多くは「自分は差別をしているつもりはないのに、属性 ( 白人・男性であること ) だけを理由に採用や昇進、大学入学で不利に扱われている」と感じており、これを「逆差別」と呼ぶ。この主張が客観的に立証された事実であるかどうかは論争の対象であるが、そう感じ、そう主張する層が現に存在するという点は社会的事実である。

この論点に関連する確立した事実としては、 2023 年 6 月、米連邦最高裁判所が SFFA( 公正な入学を求める学生たち ) 対ハーバード大学・ノースカロライナ大学の裁判において、大学入試における人種を考慮した優遇措置 ( アファーマティブ・アクション ) を違憲とする判断を下したことが挙げられる [4] 。これ以降、企業社会でも DEI 関連施策の縮小が相次いだ。フォード、ウォルマート、モルソン・クアーズ、ハーレーダビッドソン、トヨタなどが 2024 年に DEI 方針を見直し、 S&P500 企業の年次報告書における「 DEI 」という語の言及頻度は 2022 年の平均 12.5 回から 2024 年には 4 回程度に減少したと報告されている [5] 。企業側が公式に挙げる理由は、前述の最高裁判決による法的リスクの回避や、コスト削減であることが多い。 DEI 政策への反発そのものが唯一の要因だと断定することはできず、複数の要因が絡み合っている点には留意が必要である。

この論点についてはバランスを取って両論を紹介する必要がある。 DEI 政策の擁護派は、機会の公正な配分のためには、過去から続く構造的な障壁 ( 採用時の無意識のバイアス、人的ネットワークの偏りなど ) を補正する積極的措置が必要だと主張する。彼らにとって DEI は「逆差別」ではなく、これまで見過ごされてきた不公正を是正する手段である。一方、 DEI 批判派は、属性に基づく優遇はメリトクラシー ( 能力主義 ) の原則に反し、当事者個人の能力とは無関係な基準で人生の機会が左右されることそのものが不公正だと主張する。両者はいずれも「公正さ」を掲げながら、その内実 ( 結果の公正か、手続きの公正か ) について異なる理解に立っている。この対立は、単純な善悪では割り切れない、現代民主主義社会が抱える本質的な価値対立の一つである。

(3) 支持構造の多様性

前述の通り、非白人層への支持拡大は、トランプ支持を単純な「白人の人種的反動」として説明する図式の限界を示している。若い世代の黒人男性やヒスパニック男性の一部が、経済的な実利 ( 物価・雇用 ) や、文化的な保守性 ( 家族観、宗教観 ) を理由に共和党側に接近している現象は、既存の政治的アイデンティティの再編成が進行していることを示唆する分析であり、確定した因果関係というよりは、今後さらに検証を要する仮説として理解すべきである。

不満の伏線としての「オバマ政権期」

トランプ現象の起点を 2016 年に置くのは不十分である。多くの分析が、その伏線をオバマ政権期 (2009 〜 2017 年 ) に見出している。

第一に、 2008 年の世界金融危機からの回復過程における格差の構造である。統計データによれば、金融危機後、白人・黒人・ヒスパニックいずれの世帯も資産価値が約 25% 下落したが、その後の回復速度には人種間で明確な差があった。白人世帯の資産は 2010 年から 2013 年にかけて相対的に安定化した一方、非白人世帯は下落が続いた。株式市場が 2013 年に完全に回復した一方で、失業率はなお 8% 前後、世帯の中央値資産は危機前の水準を長期間下回り続けた [6][7] 。この「株価は回復したが生活実感は回復しない」という非対称性は、白人労働者層を含む中間層全体に「エリートだけが回復の恩恵を受けている」という感覚を広げた、というのが有力な解釈である。ただし、この感覚がどの程度「白人であること」に紐づいていたのか、それとも階層一般の問題だったのかについては、研究者の間でも見方が分かれており、断定はできない。

第二に、バラク・オバマという米国初の黒人大統領の存在そのものが持った象徴性である。オバマの当選は、人種的分断を乗り越える象徴として肯定的に受け止められた一方、一部の保守層にとっては、自らが慣れ親しんできた社会的・文化的な基準の急速な変化を象徴する出来事として受け止められた側面があるとする分析がある。これは実証的に測定が難しい心理的反応であり、「投機的・論争的な主張」の領域に属することを明記しておく。

第三に、この時期にアイデンティティ・ポリティクス ( 人種・性別・性的指向などの集団的属性を基盤とした政治的主張 ) が公共言説の前面に表面化したことも、確立した事実として指摘できる。 2013 年に始まったブラック・ライヴズ・マター (BLM) 運動はその代表例であり、警察の暴力や構造的人種差別への異議申し立てとして広範な支持を集める一方、一部の保守層からは「自分たちの経験や不満は顧みられていない」という疎外感を強めさせる要因として作用したとする指摘がある。

不満の政治資源化のメカニズム

ここまで見てきたような複合的な不満・不安の感情は、それ自体では政治的な力にならない。それが特定の方向へ組織化され、動員される過程にこそ、ポピュリズムの核心的なメカニズムがある。以下の三つの回路に整理できる。

問題の単純化 — 敵の名指し

経済的停滞、文化的変容、制度への不信といった複雑で多因子的な問題は、そのままでは有権者にとって理解し行動する対象になりにくい。ポピュリズムの政治的技法は、この複雑さを「善良な人民」対「腐敗したエリート」「特定の集団」という単純な二項対立に還元することにある。これにより、複雑な構造的問題への処方箋を提示する代わりに、名指しされた「敵」を打倒することが問題解決であるかのような物語が成立する。これは政治学における「ポピュリズム」の定義に近い、比較的確立した分析枠組みである。

経済問題からアイデンティティ問題への転換

製造業の衰退や賃金の停滞といった、本来は税制・産業政策・教育投資といった構造的な対応を要する経済問題が、しばしば「誰が悪いのか」という属性の問題 ( 移民、特定の人種集団、グローバル企業 ) へと転換されて語られる。これは、経済的な処方箋が効果を発揮するまでに長い時間を要し、政治的には成果が見えにくいのに対し、「敵」を名指しし、その象徴的な排除 ( 国境管理の強化、特定政策の撤廃 ) を示すことは、政治的には即効性のある成果として提示しやすいためだと説明される。この転換のメカニズム自体は多くの政治学者が指摘するところだが、個々の政治家がどこまで意図的にこれを行っているかは、事例ごとの検証を要する解釈的な主張である。

SNS ・アテンション・エコノミーとの共振

この単純化の物語は、現代の情報環境と強く共振する。「アテンション・エコノミー」とは、経済学者ハーバート・サイモンが 1971 年に提起した概念で、情報が過剰にあふれる社会では、希少な資源はもはや情報そのものではなく、それを処理する人間の「注意力」であるとする考え方を指す [8] 。この枠組みに基づけば、 SNS のアルゴリズムは利用者の関与 ( 閲覧・共有・反応 ) を最大化するように設計されており、複雑で退屈な構造的説明よりも、怒りや恐怖といった強い感情を喚起する単純な物語のほうが拡散されやすい。この技術的傾向が、前述の「敵の名指し」型の政治的レトリックと親和的であることは、多くのメディア研究者が指摘する構造であるが、これがポピュリズムの「原因」なのか、既存の傾向を「増幅する媒体」に過ぎないのかについては、なお学術的な議論が続いている。

熟議の質を高めるための方策

不満の政治資源化という現象を批判するだけでは、対案にならない。民主主義の側にどのような処方箋がありうるかを、三つの方向から検討する。

メディアリテラシー教育

感情を煽る情報とそうでない情報を見分け、一次情報にあたる習慣を市民に育てる教育は、即効性はないものの、長期的な耐性を作る基盤的な施策である。ただし、メディアリテラシー教育だけで構造的な経済的不満を解消できるわけではない点には注意が必要であり、これを万能薬として過大評価すべきではない。

熟議民主主義 — ミニ・パブリックスという実践

「熟議民主主義」とは、単に多数決で意思決定するのではなく、市民が十分な情報と時間を与えられた上で対話を重ね、合意形成を目指す民主主義のあり方を指す概念である。その具体的な制度形態の一つが「ミニ・パブリックス ( 市民議会 ) 」であり、無作為抽出で選ばれた市民が、専門家からの情報提供を受けながら特定の政策課題について議論し、政策提言をまとめる仕組みである。

アイルランドはこの分野で最も注目される実例を提供している。同国は 2016 年から 2018 年にかけて市民議会を開催し、その提言が同性婚合法化 (2015 年 ) や妊娠中絶に関する憲法改正といった、社会的に対立の激しい論点における国民投票の実施につながった [9] 。米国オレゴン州や、ベルギーのドイツ語共同体、フランスの気候市民会議など、同様の枠組みは各国で試行されている。これらの事例が示すのは、対立的な論点であっても、十分な情報と時間、そして無作為抽出による代表性が確保されれば、単純な敵味方の対立を超えた合意形成が可能になりうるという知見である。ただし、これらの制度はいまだ実験的段階にあり、大規模な国政レベルでの恒常的な意思決定機構として機能した実績は限定的である点も付言しておく。

課題解決型リーダーシップと社会的包摂

最後に、政治指導者の役割がある。不満を「敵」への攻撃に変換するのではなく、具体的な政策課題 ( 職業訓練、地域経済の再建、医療・教育へのアクセス ) への取り組みとして再定義し、対立する集団の双方が具体的な便益を実感できる形で問題を解決していくリーダーシップのあり方が求められる。同時に、経済的に取り残されたと感じる層の不満を「差別的だ」と切り捨てるのではなく、その根底にある正当な生活上の不安を認めた上で対話することも、社会的包摂の一部として重要である。これは規範的な提言であり、実証的に効果が測定された処方箋というより、望ましい方向性についての一つの見方であることを明記しておく。

民主主義における知性の役割

本稿で見てきたように、現代政治における不満は、単一の原因や単一の集団の責任に帰することのできない、複合的な構造から生まれている。経済のグローバル化がもたらした痛みと恩恵の不均等な分配、人口構成やアイデンティティをめぐる価値観の急速な変容、そしてそれらの複雑さを単純化し、特定の「敵」への怒りへと変換する情報環境。これらが絡み合って、今日の政治的分断を形作っている。

だからこそ、有権者に求められる姿勢は、自らの不満や不公平感を否定することではなく、その感情がどのような構造から生まれ、誰によってどのように利用されうるのかを見極める知性である。ここで言う「知性」の内実を具体的に検討しないまま、単に「市民はもっと賢くなるべきだ」と唱えるだけでは、規範論の域を出ない。以下では、その知性が何を指すのか、それがどのように個人の努力に還元されない社会的条件と結びつくのかを、四つの角度から掘り下げる。

「知性」とは何を指すのか — 学歴でも情報量でもない

まず誤解を避けておきたい。ここで論じる知性とは、高学歴であることや、政策の詳細を数多く記憶していることを意味しない。実際、学歴と「不公平感の政治化」への耐性との相関は、経験的にはさほど単純ではない。むしろ重要なのは、認知心理学で「メタ認知」と呼ばれる能力、すなわち「自分がなぜそう感じ、そう信じているのか」を一段上から観察する能力である [10] 。具体的には次の三つの要素に分解できる。

  • 帰属の複数性を保持する能力。 自分の生活が苦しい理由を、単一の「敵」( 移民、エリート、特定の人種集団 ) に帰属させず、複数の構造的要因 ( 技術変化、貿易、税制、教育投資の配分など ) が同時に作用している可能性を保持し続ける能力である。単純化は認知的に「楽」であり、複数要因を保持する態度は絶えず努力を要する。
  • 自分の感情の出所を疑う習慣。 ある政治的主張に触れて強い怒りや恐怖を感じたとき、その感情が「情報の内容」によって引き起こされたのか、それとも「情報の提示の仕方」( アテンション・エコノミーが仕掛ける演出 ) によって引き起こされたのかを区別しようとする習慣である。
  • 敵対する側の主張を、最も説得力のある形で再構成する能力。 哲学で「善意の解釈 (principle of charity) 」と呼ばれる態度に近い [11] 。 DEI 政策の擁護派・批判派のどちらの立場であれ、相手の主張を歪めた「藁人形」ではなく、相手が実際に信じている最も強い形で理解しようとする努力がこれに当たる。

これらはいずれも、生まれつきの資質というより、訓練によって伸ばしうる技能である。したがって「知性の役割」を論じることは、暗に「一部の市民は知的に劣っている」という含意を持つ危険な語り方になりやすい。そうではなく、これは万人が置かれた情報環境の設計と、教育を通じた技能形成の問題として捉えるべきである。

単純化への抵抗という知的作業の困難さ

この種の知性を発揮することは、口で言うほど容易ではない。第一に、単純化された物語は認知的な負荷が低く、複雑さを保持し続ける態度は精神的なコストを伴う。多くの市民は、生活のための労働に時間を割かれ、政治的な事象に十分な熟考の時間を割く余裕自体を持たない。この意味で、知性の発揮を個人の意志の問題に帰することは、時間的・経済的資源の不平等を見えなくしてしまう危険がある。

第二に、単純化への抵抗は、しばしば当事者の感情そのものへの否定と誤解される。「あなたの不満は複合的な構造の産物であって、単一の敵のせいではない」という指摘は、当事者にとって「あなたの怒りは正当ではない」と言われているように響きかねない。これは本稿の第三章で論じた「逆差別」感覚の当事者にも、経済的取り残され感を持つ労働者にも同様に当てはまる。知性的な態度が、感情の否定ではなく、感情の由来を尊重した上での理解の深化であることを、伝える側が繰り返し明示する必要がある。

第三に、単純化に抗う言論そのものが、党派的な武器として利用されうるという逆説がある。「複雑な問題を単純化するな」という主張自体が、特定の政治的立場を擁護するための修辞として使われる例は珍しくない。知性を掲げることが、新たな「エリートの傲慢さ」の表現として受け取られ、むしろ反知性主義を強化してしまう可能性にも注意を払う必要がある。

制度は知性を代替できない、しかし支援はできる

前章で論じたメディアリテラシー教育や熟議民主主義のミニ・パブリックスは、まさにこの意味での知性を、個人の資質にのみ依存させず、社会的に育成・発揮させるための制度的な足場である。ミニ・パブリックスが機能する理由の一つは、無作為抽出で選ばれた市民が、十分な時間と専門家からの情報提供を与えられることで、通常の政治的言説の場では発揮しにくい「帰属の複数性を保持する能力」を、制度的に支援された環境の中で発揮できるようになる点にある。つまり、知性は個人の内側だけに存在するのではなく、それを引き出す環境の設計によって、大きく変動する。

この観点から見ると、望ましい方向性は次のように整理できる。

  • 情報環境の設計を、感情喚起の最大化から、理解の質の最大化へ転換する。 SNS のアルゴリズムが engagement( 関与 ) を最大化するように設計されている限り、個々の市民がどれだけ知的な努力をしても、環境そのものが単純化と怒りの物語を優先的に増幅する。プラットフォームの設計原理、あるいはそれに対する規制の在り方は、知性の問題と不可分である。
  • 複雑さを「翻訳」する中間的な制度・職業を厚くする。 学術的な知見と有権者の生活実感の間を橋渡しする、信頼できる報道機関、地域に根ざした専門家、独立系ファクトチェック機関などの存在は、個々の市民がすべてを一次資料から自力で判断する負荷を引き下げる。知性の社会化とは、こうした「翻訳者」の層を制度的に支えることでもある。
  • 教育制度において、結論としての知識よりも、判断のプロセスそのものを教える。 特定の政策の正しさを教えるのではなく、対立する二つの主張がそれぞれ何を「公正」と定義しているのかを比較し、その違いを言語化する訓練 ( 本稿における DEI 論争の両論併記のような手法 ) を、初等・中等教育の段階から組み込む余地がある。

ただし、これらの制度的支援は、いずれも知性の発揮を「容易にする」ものであって、「自動化する」ものではない。制度が整っても、それを用いるかどうかは、最終的には個々の市民の選択に依存する。制度と個人の意志は、代替関係ではなく補完関係にある。

民主主義にとっての知性の限界と、それでも手放せない理由

ここまでの議論には、看過できない限界がある。知性の涵養を訴えることは、それ自体が緩やかな時間軸を前提とした処方箋であり、目の前の分断や不公平感の即時の解消を約束するものではない。経済的に追い詰められた労働者や、機会を奪われたと感じる若者に向かって「もっと複雑さを保持する知性を持とう」と説くことは、当人の直面する具体的な困難に対する回答にはならない。知性の涵養は、本稿の前章で論じた課題解決型リーダーシップや経済的包摂と並走してはじめて意味を持つのであり、それ単独で分断を解消できるという期待は、それこそが単純化の一種であることを自覚しておく必要がある。

それでもなお、知性という論点を手放すべきではない理由がある。政策的な処方箋がどれほど整っても、それを設計し、選び、支持し、修正していく主体は、最終的には市民自身である。経済的包摂の制度も、熟議のための場も、それを機能させる市民の側の理解と参加なしには、形だけの制度に終わる。同時に、本稿自身も、複雑な現象を単純な図式に還元する誘惑と無縁ではない。トランプ支持層の主張を「不合理な被害妄想」として片付けることも、逆に彼らの不満をすべて「客観的な不公正の証明」として扱うことも、いずれも単純化の罠である。民主主義が敵味方の単純化に呑み込まれずに機能し続けるための最後の防波堤は、制度でも技術でもなく、こうした単純化への誘惑に抗おうとする、一人ひとりの市民の知性の集積と、その知性を育て、発揮しやすくする社会的条件を整え続ける、地道な制度的努力の両方にほかならない。
