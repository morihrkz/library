論考 / POLITICAL SCIENCE

正統性の政治学 - 権威主義国家はなぜ歴史を書き換えるのか

国家が支配の正しさをどこに求めるかという視点から、権威主義体制の比較と民主主義国の現在地を読み解く

なぜ権威主義国家は、しばしば手間と外交的コストを払ってまで歴史を書き換えようとするのか。ロシアは独ソ戦、いわゆる「大祖国戦争」の記憶を国家統合の中核的な物語として法律で保護し、その記憶に反する言説を犯罪とする法整備まで行った。中国共産党は結党百周年にあたる 2021 年、党の歩みを総括する「歴史決議」を採択し、アヘン戦争以来の「屈辱の世紀」から国家再興へと至る物語を公式化した。北朝鮮は金一族の権力継承のたびに、白頭山という特定の山にまつわる神話を再構成し、金正恩体制のもとでは「白頭の血統」という言葉が公式イデオロギーの中核に据えられるまでになった。

一見すると、これらは単なるプロパガンダや権力者の自己満足に見えるかもしれない。しかし政治学の視点から見れば、これは驚くほど一貫した合理的行動である。
国家、とりわけ選挙という審判の仕組みを持たない権威主義体制は、暴力装置 - 軍・警察・治安機関 - だけで統治を維持することはできない。統治される側が「この政権には従うべき理由がある」と、積極的にせよ消極的にせよ受け入れて初めて、統治のコストは劇的に下がる。
この「従うべき理由」を政治学では正統性 (legitimacy) と呼ぶ。歴史の書き換えは、この正統性を調達するための、費用対効果に優れた手段のひとつなのである。

だが、ここでもうひとつの疑問が浮かぶ。同じ一党支配体制でありながら、ベトナムやシンガポールは、ロシア・中国・北朝鮮ほど積極的に歴史や外部の敵を政治利用しているようには見えない。
単に「権威主義体制だから歴史を歪める」という図式では、この違いを説明できない。

本稿は、「正統性の源泉」という分析軸を用いて、この謎を解きほぐすことを試みる。
そしてこの視点は、権威主義体制を分析するためだけの道具ではない。むしろ、選挙という制度によって正統性の調達過程が「見えにくくなっている」だけの民主主義国家を理解するうえでも、同じ枠組みは有効に機能する。
以下ではまず「正統性」という概念そのものを整理したうえで、ロシア・中国・北朝鮮の歴史の政治利用を比較し、それとは対照的な道を歩むベトナムとシンガポールの事例を検討する。そのうえで最後に、この視点を私たち自身が生きる民主主義国の現在 - 政治的分極化やポピュリズムの高まり - に投げ返してみたい。

政治学における「正統性」の議論の出発点は、ドイツの社会学者マックス・ウェーバー (Max Weber 、 1864 〜 1920 年 ) である。ウェーバーは、死後に編纂された大著『経済と社会』や、 1919 年の講演「職業としての政治」の中で、人がなぜ権力者の命令に従うのかという問いを、「支配の正統性」という観点から三つの理念型に整理した [1] 。

第一に伝統的支配。「昔からそうだったから」という慣習・伝統への信仰に基づく支配であり、世襲の王政などがその典型である。
第二にカリスマ的支配。指導者個人の非凡な資質 - 英雄性、預言者的な力、あるいは単なる強烈な個性 - への心酔に基づく支配で、革命指導者やカルト的な政治家に見られる。
第三に合法的支配。特定の人物への信仰ではなく、あらかじめ定められた法や手続きそのものへの信頼に基づく支配であり、近代官僚制国家や現代の民主主義国家の大半はこの類型に属する。
ウェーバー自身は、これらを現実の政治体制を分類するための厳密なラベルではなく、複数が混ざり合って現れる分析上の道具、いわゆる「理念型」として位置づけていた点には注意が必要である。

ウェーバー以後の比較政治学、とりわけ権威主義体制を専門とする研究群は、この枠組みをさらに実務的な形に細分化してきた。論者によって呼称や区分の仕方には幅があるが、現代の権威主義体制研究では、政権が動員する正統性の源泉を、おおむね次の四つに整理することが多い。
本稿でもこの四分類を分析の軸として用いる。

  • 業績正統性 (performance legitimacy) - 経済成長や治安の安定、生活水準の向上といった「結果」によって支配を正当化する。
  • イデオロギー的正統性 - 共産主義や特定の国家理念、宗教的世界観など、体制が掲げる思想への支持に基づく。
  • カリスマ的正統性 - ウェーバーの用語をそのまま借りたもので、指導者個人の権威・カリスマに依拠する。
  • 歴史的正統性 - 体制の起源や指導者の系譜を、民族の受難や栄光の物語に結びつけることで正当性を調達する。

権威主義体制の多くは、この四つの源泉を単独ではなく組み合わせて用いる。次章で見るロシア・中国・北朝鮮は、いずれも歴史的正統性を重視する点で共通するが、その動員の仕方 - どのような歴史を、どのように語るか - は驚くほど異なっている。

ロシア・中国・北朝鮮はいずれも、歴史的正統性を統治の重要な柱としている点で共通する。しかし、その手法を仔細に見ると、少なくとも三つの異なる型に分かれることが分かる。
本稿ではこれを便宜的に「反論型」「選択的記憶型」「神話創造型」と呼ぶ。これは学界で確立した固有の分類名というより、以下で述べる各国の特徴を整理するために本稿が用いる分析上のラベルである。

ロシア - 「反論型」歴史修正

ロシアにおける歴史的正統性の中核は、第二次世界大戦、ロシアで言うところの「大祖国戦争」における対独戦勝の記憶である。毎年 5 月 9 日の対独戦勝記念日は、ロシアで最も重要な国民的祝祭であり続けている。
この記憶を守るため、ロシアは 2014 年、ナチズムの美化やソ連の対独戦における役割について虚偽の情報を広めることを犯罪とする法律 - 刑法 354 条の一を新設するいわゆる「ナチズム復権禁止法」 - を制定した [4] 。 2020 年の憲法改正では、新設された第 67 条の一に、歴史的真実の擁護と祖国防衛者の記憶の保護を国家の責務として明記するに至っている [5] 。

この文脈で象徴的なのが、プーチン大統領が 2021 年 7 月に発表した論文「ロシア人とウクライナ人の歴史的一体性について」である [3] 。同論文は、ロシアとウクライナの歴史的な一体性を強調し、ウクライナの独自の国民的アイデンティティやソ連からの独立の正統性に疑義を呈する内容を含んでいた。
この論文が、後のロシアによるウクライナ侵攻の思想的背景の一つとして国際的に強く注目されたことは、多くの研究者や国際機関が指摘するところである。

ここでロシアの手法を「反論型」と呼ぶのは、その論理構成が、西側やウクライナ側の歴史認識 - ロシアからすれば自国の物語を脅かすとみなす言説 - に対する防御・反駁として組み立てられる傾向が強いためである。 NATO の東方拡大をめぐる経緯や、ソ連の対独戦における役割の評価、ウクライナの国民的アイデンティティの起源など、いずれも「相手の主張にどう反論するか」という構図の中で歴史が動員される。
なお、 NATO 拡大の経緯やソ連解体前後の外交上の「約束」の有無については、当事者間・研究者間でなお評価が分かれる論点であり、本稿はロシア側の主張の当否そのものを判定するものではない。

中国 - 「選択的記憶」型

中国共産党の歴史語りの土台にあるのは、 1840 年のアヘン戦争に始まる「屈辱の世紀」の物語である。
2021 年 11 月、中国共産党第 19 期中央委員会第六回全体会議は、結党百年を総括する「党の百年奮闘の重大な成果と歴史的経験に関する決議」を採択した [6] 。この決議は、アヘン戦争後の中国が半植民地・半封建社会に転落し「深い屈辱」を味わったと総括したうえで、共産党の指導によって香港・マカオの主権回復など「屈辱の世紀」に終止符が打たれたという物語を公式化している。
この決議は、 1945 年の毛沢東による決議、 1981 年の鄧小平による決議に次ぐ、党史上三番目の「歴史決議」である。

中国の手法の特徴は、選択的な強調と縮小の組み合わせにある。
たとえば 1981 年の決議は、文化大革命 ( 1966 〜 1976 年 ) について「建国以来もっとも深刻な挫折と損失を党・国家・人民にもたらした」と公式に認め、これを「指導者の誤りによって引き起こされ、反革命集団に利用された」動乱と位置づけた [7] 。この 1981 年決議の評価は今日まで党の公式見解として維持されているが、具体的な犠牲者数や個々の弾圧の実態についての公的な議論は依然として限定的である。
さらに、 1950 年代末の大躍進政策に伴う大飢饉の死者数は公式統計として発表されておらず、 1989 年の天安門事件に至っては、文化大革命のような「誤りであった」という限定的な公式総括すら存在せず、国内の公的言説からほぼ完全に排除されている。同じ「不都合な過去」であっても、その扱われ方には明確な濃淡があるという点が、中国の歴史政治の特徴だと言える。

北朝鮮 - 「神話創造」型

北朝鮮の正統性の物語の中心にあるのは、中朝国境にまたがる白頭山 ( 中国名・長白山 ) である。白頭山は朝鮮半島の建国神話における始祖・檀君生誕の地として古くから神聖視されてきた土地だが、北朝鮮の公式史観はここに金一族の物語を重ね合わせる。すなわち、金日成がこの山を拠点に抗日パルチザン闘争を戦い、その子である金正日もまた同地の秘密キャンプで 1942 年に生まれたとする物語である [8] 。
もっとも、国外の研究者の多くは、金正日は実際には旧ソ連極東地域 ( 現ロシア・ハバロフスク地方 ) で 1941 年に生まれたと見ており、これは北朝鮮国外ではおおむね有力視されている見立てである。北朝鮮国内でこの点を検証する手段は事実上存在せず、確定的な一次資料も乏しいため、本稿はどちらが「事実」であるかを断定する立場にはないが、少なくとも北朝鮮国内の公式説明と国外の歴史研究の間に明確な乖離があることは指摘しておきたい。

「白頭の血統」という言葉自体は比較的新しく、金正恩への権力継承が本格化した 2000 年代以降に広まった概念であり、 2013 年に改定された北朝鮮の事実上の最高規範「唯一的領導体系確立の十大原則」第 10 条第二項には、党と革命を「永遠に」白頭の血統によって継承すると明記されるに至った [9] 。
これは、単に過去の出来事を選択的に語るというより、検証がきわめて困難な建国神話そのものを新たに創出・公式化する作業に近い。北朝鮮が置かれた特殊な条件 - 国際的な経済制裁下にあり業績正統性を発揮しにくく、複数政党制もイデオロギー上の開放性も持たない - を踏まえれば、世襲による権力継承を正当化する神話への依存度が突出して高くなるのは、ある意味で必然的な帰結だとも言える。

ロシア・中国・北朝鮮の共通点を踏まえると、「一党支配体制は歴史を政治利用し、対外的な敵意を動員することで正統性を調達する」という命題は、それなりの説得力を持って見える。しかし同じ一党独裁体制でありながら、ベトナムはこの図式にきれいには当てはまらない。

ベトナムが中国に対して抱く歴史的な警戒感は、決して希薄なものではない。むしろ、ロシアや中国が動員する歴史よりも、はるかに具体的で根深い実体を持つ。ベトナムは紀元前後から千年以上にわたって中国王朝の支配下に置かれた歴史を持ち、独立後も幾度となく中国との軍事的緊張を経験してきた。
その最も新しい記憶が、 1979 年の中越国境紛争である。カンボジアに侵攻してポル・ポト政権を打倒したベトナムに対し、中国が「懲罰」を掲げて越境攻撃を行ったこの戦争では、双方合わせて数万人規模の死者が出たとされるが、正確な数字については双方の発表に開きがあり、確定的な統計は存在しない [10] 。
興味深いことに、 1991 年の国交正常化以降、この戦争は両国の公的な言説からほとんど姿を消しており、双方の政府とも記念行事などでこの戦争に触れることを避ける傾向が続いている。加えて南シナ海 ( ベトナムでは東海と呼ばれる ) の島嶼をめぐる対立も、現在進行形の火種であり続けている。

つまりベトナムは、ロシアや中国よりもよほど「歴史を対外的な敵意動員に使う実質的な理由」を持ちながら、それをほとんど行っていない。この逸脱はどこから来るのか。

ここでまず公平のために、反対の見立ても検討しておきたい。すなわち「ベトナムが歴史を動員しないのは、単に今のところ経済的に順調で、その必要に迫られていないからにすぎない。もし深刻な経済危機や体制の正統性の危機に直面すれば、ベトナムもまた中国やロシアと同様、歴史的・民族主義的な動員に訴えるはずだ」という見方である。
この見立てには一定の説得力がある。実際、ベトナム共産党自身、フランスからの独立戦争 ( 1945 〜 1954 年 ) やいわゆるベトナム戦争 ( 1955 〜 1975 年 ) の記憶を、国内向けの歴史的正統性の柱として現在も用いている。
つまりベトナムは「歴史を使わない国」なのではなく、「歴史を対外的な敵意動員には使わない国」というべきである。この対内 / 対外の使い分けにこそ、ベトナムの特徴がある。

その背景には、 1986 年に始まったドイモイ ( 刷新 ) 政策以降の、徹底した全方位外交がある。ベトナム共産党の故グエン・フー・チョン書記長が「太い根、頑丈な幹、しなやかな枝」を持つ竹にたとえて定式化したとされる、いわゆる「竹の外交」である [12] 。
この方針は 2019 年の国防白書で「四つのノー」政策として明文化された。軍事同盟を結ばない、一国と結んで他国に対抗しない、外国に軍事基地を提供しない、そして武力行使や武力による威嚇を行わない、という四原則である [11] 。

この全方位外交の到達点を象徴するのが、対米関係の劇的な進展である。ベトナムと米国は 1995 年 7 月 11 日に国交を正常化し、 2023 年 9 月 10 日、ハノイを訪れたバイデン米大統領とチョン書記長の会談により、両国関係はベトナムの外交序列で最上位にあたる「包括的戦略パートナーシップ」に格上げされた [13] 。両国の貿易額は、正常化当初の 1995 年には 4 億 5100 万ドルにすぎなかったが、 2023 年には約 1240 億ドルにまで拡大している [14] 。
注目すべきは、ベトナムがこの対米関係の格上げと並行して、中国・ロシアとも同格の「包括的戦略パートナーシップ」を維持している点である。かつての戦争相手であった米国とも、歴史的な後ろ盾であり続けるロシアや、警戒対象である中国とも、同時に最高レベルの関係を築くという芸当は、イデオロギーよりも実利を徹底して優先する姿勢の表れだと言える。

この実利重視の姿勢は、スポーツや観光といった分野にも表れている。
2025 年 9 月、ダナンで開催された国際大会「 PPA ツアー・アジア MB ベトナムカップ 2025 」は、 7906 人の観客を集め、ピックルボール競技における最多観客動員数としてギネス世界記録に認定された [16] 。さらにベトナムは、 2026 年 8 月 30 日から 9 月 6 日にかけて、同じくダナンで「ピックルボール・ワールドカップ 2026 」を開催する権利を獲得しており、これはこの大会がアジアで開催される初めての事例となる [15] 。
イデオロギー的な意味合いをほとんど持たないこうした国際スポーツイベントの誘致に積極的なことは、対外的な敵意動員とは対照的な、経済的実利と国際的な可視性の獲得を志向するベトナム外交の姿勢を象徴する一エピソードとして興味深い。

シンガポールもまた、一党優位体制でありながら対外的な敵意動員をほとんど行わない国の代表例である。シンガポールの人民行動党 (PAP) は、 1959 年の自治獲得以来、実に六十年以上にわたって政権の座を維持し続けている [17] 。
法制度上、シンガポールは複数政党制であり、野党の立候補や議席獲得も認められている。 2025 年 5 月 3 日に実施された総選挙では、ローレンス・ウォン首相 ( 2024 年 5 月にリー・シェンロン前首相から政権を継承 ) のもとで初めての選挙が行われ、 PAP は全 97 議席中 87 議席を獲得し、得票率も前回 2020 年の 61.2% から 65.57% へと上昇する圧勝を収めた。最大野党の労働者党 (WP) は既存の地盤を守り、議席数自体は維持したものの、新たな選挙区での勢力拡大には至らなかった [18] 。
制度上は競争的な選挙が存在しながら、実質的には長期にわたる一党優位が続いているという点で、シンガポールは「合法的支配」と「業績正統性」がきわめて強く結びついた事例だと言える。

シンガポールがロシア・中国・北朝鮮のような対外的敵意動員に頼らない背景には、二つの構造的な制約がある。
第一に、多民族国家としての成り立ちである。 1965 年の独立は、マレーシアからの分離という経緯に加え、 1964 年や 1969 年に生じた人種暴動の記憶を伴うものであった。この経験から、シンガポール政府は中国系・マレー系・インド系・その他という区分 ( いわゆる CMIO モデル ) を前提に、意図的な多民族主義政策を国是として掲げてきた。
多民族社会において特定の外部民族・国家への敵意を煽ることは、国内の民族間関係にただちに跳ね返ってくる危険な火遊びであり、統治の安定を損なう自傷行為になりかねない。

第二に、貿易依存度のきわめて高い経済構造である。シンガポールの貿易総額の対 GDP 比は 2022 年時点で約 333% に達し、世界でも突出して高い水準にある [19] 。
中継貿易拠点・国際金融拠点としての性格を色濃く持つシンガポール経済にとって、特定の貿易相手国や地域を「敵」に設定することは、自国の存立基盤そのものを脅かす。ロシアや中国のように資源や巨大な国内市場を背景に一定の経済的自己完結性を持つ大国とは異なり、シンガポールにとって対外的な敵意動員は、割に合わないどころか自滅的な選択肢なのである。

この結果、シンガポールの正統性は、経済成長・治安の安定・効率的で腐敗の少ない統治といった業績正統性にほぼ全面的に依拠する構造になっている。逆に言えば、この業績が大きく揺らいだとき、シンガポールがこれまでと同じ統治の安定を維持できるかどうかは、まだ十分に検証されていない未知数だとも言える。

COLUMN / 大韓民国の「親日清算」をどう読むか

ここで一息入れて、少し寄り道をしたい。ここまで見てきたのは、選挙という審判装置を持たない国々が歴史をどう扱うかという話だった。
では、その装置をきちんと備えた国が、同じくらいの熱量で過去を掘り返すとき、それは何を意味するのだろうか。関係があるとも、ないとも言える事例として、大韓民国を取り上げてみる。

八十年後に確定される「名簿」

韓国では、日本統治期に日本側に協力したとされる人物 - いわゆる親日派 - を特定し、公的な記録として確定する作業が、独立から八十年を経た現在も続いている。 2004 年に制定された「日帝強占下反民族行為真相糾明に関する特別法」に基づき、大統領直属の委員会が 2005 年から 2009 年にかけて調査を行い、おおよそ千名を「親日反民族行為者」として公式に認定した [21] 。
民間の民族問題研究所も 2009 年、 4,389 名を収録した『親日人名辞典』を刊行している [23] 。

さらに 2005 年には、親日行為によって得られた財産を国庫に帰属させる特別法が制定された。子孫が相続した財産にまで法的効果が及ぶこの仕組みについて、韓国の憲法裁判所は 2011 年に合憲との判断を示している [22] 。
この立法の直接の引き金は、 1990 年代に李完用 - 韓国併合条約に署名した当時の大臣であり、韓国では「売国奴」の代名詞となっている人物 - の子孫が祖先名義の土地の返還を求めて提訴し、一部で勝訴したことへの世論の反発であったとされる。

そして、この作業は歴史学の営みにとどまらない。名簿は、いま生きている人々の家系へと接続していく。
大韓民国の国歌「愛国歌」の作曲者である安益泰についてすら、日本統治期の活動をめぐる資料が公にされて以降、国歌そのものを変えるべきだという議論が繰り返し提起されてきた。芸能関係者や著名人について、曽祖父の代の行動が調べ上げられ、本人には何の関与もない過去について公の場で釈明や謝罪を求められる - そうした場面が、この二十年ほどのあいだ繰り返し生じている。

権威主義国家の歴史動員と通底するもの

では、これはロシアや中国や北朝鮮がやっていることと、地続きなのだろうか。少なくとも三点において、構造は明らかに似ている。

第一に、過去が現在の権力配置をめぐる資源になっている点である。「誰が正統な後継者か」を、過去の物語によって決める構図は共通する。
第二に、受難の物語が国民統合の核に据えられている点である。中国の「屈辱の世紀」と、植民地支配という受難の記憶は、正統性の調達装置としての役割において相似形をなす。
第三に - そしてこれが最も鋭い相似点だが - 法によって史観を裏書きする形式である。ロシアが記憶法制によって「大祖国戦争をどう語るべきか」を法的に囲い込んだのと、韓国が特別法と国家委員会によって「誰が加害者であったか」を法的に確定したのとは、国家が公式の歴史解釈を法的手続きで確定するという点で、形式上ほとんど同型と言ってよい。

しかし、決定的に異なるもの

ただし、そこで話を終えてしまうと、いちばん重要なことを取り落とす。

まず、方向が逆である。権威主義国家の歴史動員は、体制にとって不都合な事実を縮小し、沈黙させ、都合の良い物語を前景化する作業だった。中国が天安門事件を公的言説から排除したように、それは基本的に「隠す」方向に働く。これに対して韓国の親日清算は、埋もれていた事実を掘り起こし、記録として残す方向に働く。少なくとも形式上は実証を競う営みであって、史料の隠蔽ではない。
次に、可逆性がある。 2015 年の日韓合意、 2018 年の「和解・癒やし財団」の解散決定、そして 2023 年の徴用工訴訟をめぐる「第三者弁済」解決策 [24] という振幅そのものが、ロシアや北朝鮮では起こりえない現象である。公式の歴史解釈が誰かに独占されていない、ということの何よりの証拠だろう。
第三に、対抗言説が国内で合法に流通する。 2019 年に刊行された『反日種族主義』が、激烈な批判を浴びながらもベストセラーとなり、公然と論争の対象になったこと [25] は、中国やロシアではおよそ想像しがたい。
第四に、動員の主体が政府だけではない。民間の研究団体、司法、報道機関、そして世論が入り混じっており、党と国家が独占する権威主義国の構図とは根本的に異なる。

コラム図表 権威主義国家の歴史動員と、韓国の「親日清算」の対照
論点権威主義国家の歴史動員韓国の「親日清算」

本稿の枠組みに置き直すと

この事例は、本稿の分析軸の上ではベトナムのちょうど逆像として位置づけられる。ベトナムは、歴史的正統性を対内的には用いながら、対外的な敵意動員には用いなかった。韓国の場合は、対内的な正統性闘争 - 大韓民国の正統性を独立運動の系譜に置くのか、それとも建国と産業化の実績に置くのか - が、日本という外部を経由して表現される構造になっている。
その根には、建国時の「未清算」がある。李承晩政権下で反民族行為特別調査委員会が一年ももたずに解体され、植民地期の官僚機構や警察をほぼ温存したまま国家が出発したこと、後に長期政権を築いた朴正煕が満洲国軍の将校であったこと。この経緯があるかぎり、親日清算は過去の問題ではなく、現在の政治陣営どうしが互いの正統性を測り合うための物差しであり続ける。対外的な敵意は、目的そのものというより、国内の正統性闘争が外に漏れ出したものだという側面を持つ。

ここから引き出せる論点は、次章の主題を先取りするものでもある。すなわち、民主主義であることは歴史動員の歯止めにはならない、ということだ。
権威主義体制では、歴史は上から動員される。民主主義体制では、票になるかぎりにおいて、下からの需要に応えるかたちで供給される。前者には制度的な停止装置がないが、後者の停止装置も結局は有権者の関心の移ろいでしかない。
だからこそ大きく振幅するのであり、振幅すること自体は健全さの証でもあれば、政治的に利用しやすいという危うさの証でもある。冒頭の図で言えば、韓国はまさに「民主主義国 ( 一般 ) 」の点線の帯の上を、局面ごとに大きく往復している国だと言える。

本稿の立場について。ここでの関心は、植民地支配という歴史的事実の評価そのものではなく、その記憶が現在の政治のなかでどう用いられるかという一点にある。前者を相対化する意図はない。また、この構造は一方の国だけのものでもない。相手国の歴史動員が自国の動員を正当化する材料として使われる相互強化の回路は、日本を含む当事国のいずれもが共有している。

最後にひとつ、コーヒーが冷めないうちに。北朝鮮の「白頭の血統」は、血が栄光を伝えるという想定の上に立っている。親日派の子孫に対する責任追及は、血が罪を伝えるという想定の上に立っている。評価の符号は正反対だが、「血が価値を運ぶ」という前提そのものは共有されている。
もちろん、一方は世襲独裁を正当化する神話であり、他方は法治国家の手続きを踏んだ制度である。両者を等価と見なすのは乱暴に過ぎる。それでもこの対比は、責任は本人に帰するという近代法の大原則が、どういう場面で、どんな正当な理由を掲げて揺らぐのかを照らしてくれる鏡ではある。

COLUMN / 台湾・中国国民党の「抗日」という通貨

もう一杯だけ付き合っていただきたい。前のコラムで見たのは、民主主義国が自国の過去を掘り返す話だった。
今度は、その隣で起きているもう少し奇妙な現象を見る。民主主義国の政党が、権威主義国家の歴史の語りのほうへ、自分から歩み寄っていく場合である。

十年ぶりの国共トップ会談

2025 年 10 月 18 日、台湾の最大野党・中国国民党の主席選挙で、鄭麗文が 50.15% の得票率を得て当選した [26] 。彼女はかつて学生運動の側にあり、民進党に籍を置いていた経歴を持つ人物である。
就任後まもなく、白色テロの犠牲者を悼む集会に出席した際、追悼名簿に国共内戦期の中国共産党のスパイであった呉石が含まれていたことが判明し、党内からも批判が出るという一幕もあった。

そして 2026 年 4 月 7 日から 12 日にかけて、鄭主席は中国共産党の招請を受けて江蘇省・上海・北京を訪問し、 4 月 10 日、北京の人民大会堂で習近平と会談した [27] 。国共両党のトップ会談としては、およそ十年ぶりのことである。握手は十三秒に及んだ。
会談は約一時間の非公開で行われ、習近平の発言は録画も全文公開もされていない。公表された新華社の記事に日本への言及はなく、「社会制度の違いは分裂の口実にはならない」「『台湾独立』こそが台湾海峡の平和を損なう元凶である」といった従来の定型句が並ぶにとどまった。

南京で、日本は十回名指しされた

日本が前面に出てきたのは、会談の二日前である。 4 月 8 日、鄭主席は南京の中山陵に参拝し、孫文の霊前で談話を発表した。三千語あまりのこの演説のなかで、日本は十回前後にわたって名指しされている ( 報道によっては十一回と数えられている ) [28] 。

孫文の死を悼むことについて、彼女はこう語った。大陸では孫文を悼むことは当然かつ公然たる名誉ある行為であったが、台湾では人目を忍び、細心の注意を払い、あらゆる手立てを尽くしてそうするほかなかった、と。
台湾総督府が追悼を禁じ、弔辞を検閲したこと。台湾が植民地となったのは、そもそも中国が衰え、日清戦争に敗れたからであること。八年にわたる抗日戦争を経て日本が敗れ、ようやく台湾が五十年の植民地支配の災厄から抜け出したこと。
そして演説はこう締めくくられる - 百三十年前の日清戦争で日本帝国主義が海峡に刻みつけた傷は、今日に至るまで癒えていない、と。

台湾の大陸委員会は翌 4 月 9 日、これを厳しく批判した。副主任委員の梁文傑は、大陸を訪れること自体は構わないが、あちらに行って中国共産党の語りに唱和すべきではない、台湾の政党指導者がその語りに唱和するのは事実上中国共産党の側に立つことを意味する、と述べた [29] 。
さらに梁は、孫文自身が日本と深い関係を持っていた人物であることを踏まえれば、孫文を日本の植民地支配と戦った人物として描くのは「重大な歴史の歪曲」だとも指摘している。

なぜ日本だったのか - 正統性の在庫を数える

ここで、本稿の分析軸が効いてくる。国民党が中国共産党と向き合うとき、対等の立場で持ち出せる歴史的資産は、実はほとんど残っていない。
かつての「自由中国」対「共産中国」という物語は、和解を求める以上もはや使えない。台湾土着のアイデンティティに立脚する物語は民進党のものである。戦後の威権統治と白色テロは資産ではなく負債であり、呉石をめぐる一件は、その負債がいかに扱いにくいかを露呈させた。
そのなかで唯一、両党が共有できる通貨として残っているのが、抗日戦争と台湾光復なのである。中華民国こそが抗日戦争を戦ったのだと言えるかぎりにおいて、国民党は北京に対して物乞いではなく共同の当事者として立つことができる。南京の中山陵という場所で、孫文と抗日を持ち出すという選択は、その意味できわめて計算されている。

そしてこの構図は、前のコラムで見た韓国の事例と、形は似ていながら機能が正反対である。

需要のない市場に売る

台湾の事例で際立つのは、この動員が国内世論に対してほとんど売れる見込みがない、という点である。
日本台湾交流協会が 2024 年末から 2025 年初めにかけて行った世論調査では、「最も好きな国・地域」として日本を挙げた台湾の回答者は 76% にのぼり、過去最高を記録した [30] 。二位の韓国が 4% 、中国と米国がそれぞれ 3% であることを考えれば、これは突出した数字である。
鄭主席の訪中そのものについても、 4 月 16 日から 22 日に実施された調査では、否定的な評価が約 47% 、肯定的な評価が 35% と、否定が上回った [31] 。国民党支持層のなかでさえ、四分の一以上が評価を保留している。

つまりこれは、有権者の需要に応えて供給された物語ではない。むしろ国内では代価を払いながら、国外の相手と語りを揃えるために支出された物語である。韓国の親日清算が「票になるから加速する」ものだとすれば、台湾のそれは「票にならないのに続けられる」ものだということになる。
ここに、歴史的正統性という資源のもうひとつの性質が現れている。それは国境を越えて輸出入されうる、ということだ。自国の有権者が供給してくれない正統性を、外部の権威主義国家から調達する - 民主主義国の政党にとって、これは理屈のうえでは十分に合理的な選択でありうる。ただしその代金は、自国の有権者に対する説得力で支払われる。

公平のための留保。鄭主席自身が対外政策の場面で掲げているのは、敵意ではなく戦争回避である。日本の首相が「台湾有事は日本有事」と述べたことに対して、彼女は「台湾は無事、日本も無事、みんな無事」という言い換えを好むと語り、米国や日本を戦火に巻き込まないことこそが望みだと説明している。歴史を語る場面での敵意の喚起と、政策を語る場面での言明とは、彼女のなかで明確に分離されている。本稿が問題にしているのは前者の register であって、彼女の対外政策上の主張の当否ではない。また、五十年の植民地支配という事実そのものは事実であり、それを語ること自体が不当なのではない。問われているのは、それが誰に向けて、いつ、どの相手との共通項として持ち出されるのか、という一点である。

最後に、この二杯目のコラムの後味を記しておきたい。歴史的正統性は、それを信じてくれる聴衆がいて初めて通貨として機能する。同じ「抗日」という言葉が、北京の人民大会堂では正貨として通用し、台北の路上ではほとんど値がつかない。海峡を渡ると値段が変わるのである。
そして、その値段を最終的に決めるのは、 2026 年 11 月 28 日に投票所に向かう台湾の有権者である [32] 。権威主義体制において歴史の値付けを行うのが党と国家であるのに対し、民主主義体制ではそれが有権者に委ねられている - 本稿がここまで追ってきた区別は、結局のところこの一点に帰着する。さて、コーヒーはもう十分だろう。次章では、この区別そのものが揺らぎはじめている民主主義国一般の話に移ることにしよう。

ここまで権威主義体制、とりわけ一党支配体制における正統性調達の多様性を見てきた。しかし「正統性の源泉」という視点の真価は、権威主義体制の分析にとどまらない。
むしろ、この視点を民主主義国家に向けたときにこそ、見えてくるものがある。

しばしば「民主主義国には正統性の調達という問題がそもそも存在しない。選挙で選ばれているのだから当然正統だ」という理解がなされる。
しかし、これは半分正しく半分誤っている。より正確に言えば、民主主義国において正統性の調達が不要なのではなく、選挙という制度に埋め込まれることによって、その調達過程が「見えにくくなっている」だけなのである。

政治学では、正統性を手続き的正統性 (procedural legitimacy) と実質的正統性 (substantive legitimacy) とに区別する考え方がある。手続き的正統性とは、意思決定がどのように行われたか - 公正な選挙、透明な手続き、法の適正な運用 - に基づく正統性であり、民主主義国はこれを強く重視する。これに対して実質的正統性とは、その意思決定が実際にどのような結果をもたらしたか、人々がその結果を望ましいと感じるかどうかに基づく正統性である [2] 。
選挙という手続きは、この二つのズレを定期的に「リセット」する装置として機能する。数年に一度、業績への不満や理念上の対立を投票行動に変換し、政権交代というかたちで正統性を更新し続けることで、権威主義体制であれば体制そのものの動揺につながりかねない不満が、制度の中に吸収されていく。

しかし、この手続き的正統性と実質的正統性のあいだにズレが生じ続け、選挙という装置だけではそのズレを吸収しきれなくなったとき、何が起きるか。近年の政治学は、まさにこの局面として、ポピュリズムの台頭と政治的分極化の進行を分析してきた。
ポピュリズム政治勢力の台頭は、既存の政党政治が有権者の実質的な要求を代表できていないという、民主主義における正統性の危機への反応として理解できるという指摘がある [20] 。政治的分極化もまた、政府への信頼や選挙結果そのものの正統性に対する信認を掘り崩す要因として、近年の研究で広く論じられている。

この視点に立てば、権威主義体制の分析で用いた四つの正統性の源泉 - 業績・イデオロギー・カリスマ・歴史 - は、民主主義国の政治にもそのまま当てはめることができる。経済政策の成否が政権の支持率を直接左右する構図は業績正統性そのものであるし、文化戦争的な争点をめぐる価値観の対立はイデオロギー的正統性の争奪戦であり、強烈な個性を持つポピュリスト指導者への支持はカリスマ的正統性の一種であり、「かつての栄光」を掲げるナショナルなノスタルジアの政治的動員は、歴史的正統性の民主主義国版だと言ってよい。
権威主義国と民主主義国を分けるのは、正統性の調達それ自体の有無ではなく、その調達過程が制度によって可視化されているか、それとも選挙という装置の陰に隠されているか、という違いにすぎないのである。

図表 2 正統性の源泉と対外的敵意動員の比較マトリクス
国・体制主要な正統性の源泉対外的敵意動員の程度備考
ロシア 歴史的正統性 ( 対独戦勝 )+ カリスマ的正統性 ( 指導者個人 )+ 一部業績正統性 高い 西側・ウクライナの歴史認識への反論というかたちで対外的敵意が正当化される
中国 業績正統性 ( 経済成長 )+ イデオロギー的正統性 + 歴史的正統性 ( 屈辱の世紀からの復興 ) 中程度 ( 局面依存 ) 経済成長が鈍化するほど、歴史的・民族主義的正統性への依存が強まる傾向が指摘される
北朝鮮 カリスマ的正統性 ( 白頭の血統 )+ 歴史的正統性 ( 建国神話 ) 高い ( 恒常的 ) 業績正統性が乏しいため、神話とカリスマへの依存度が最も高い
ベトナム 歴史的正統性 ( 抗仏・抗米戦争、対内向け )+ 業績正統性 ( ドイモイ以降の経済成長 ) 低い 対中警戒という実質的な歴史的根拠を持ちながら、対外的には非動員を選択
シンガポール 業績正統性 ( 経済成長・統治効率 ) がほぼ全面的 きわめて低い 多民族構成・貿易依存経済という構造上、対外的敵意動員は自傷行為になりかねない
民主主義国 ( 一般 ) 手続き的正統性 ( 選挙 )+ 業績正統性が基本、局面によりカリスマ・歴史も浮上 文脈依存 ( ポピュリズム台頭局面で上昇 ) 手続き的正統性への依存が、業績の不振や分極化のもとで露呈しやすい

本稿は、「国家はなぜ、どのように正統性を調達するのか」という問いを軸に、ロシア・中国・北朝鮮という歴史を武器化する権威主義国家と、ベトナム・シンガポールという同じ一党支配体制でありながらそれを行わない、あるいは行う必要のない国々を比較してきた。その差異は、単純な「権威主義か否か」という区分ではなく、各国が置かれた構造的条件 - 経済的自己完結性の有無、民族構成、対外関係における実利の大きさ、そして代替可能な正統性の源泉をどれだけ持っているか - によって説明される。

ロシアと北朝鮮は、業績正統性を十分に発揮しにくい構造的制約 ( 前者は資源依存経済と国際的孤立、後者は経済制裁下の閉鎖経済 ) を抱えるがゆえに、歴史とカリスマへの依存を強めている。
中国は現在のところ高い業績正統性を維持しているが、それが今後鈍化した場合に歴史的・民族主義的動員への依存をどこまで強めるかは、この体制の今後を占ううえで重要な論点であり続けるだろう。
一方でベトナムとシンガポールは、対外的な経済的相互依存の深さと、多民族性や地政学的な脆弱性ゆえに、対外的な敵意動員そのものが自国の利益を損なう構造に置かれている。

そして、この「正統性をどこに立脚させるか」という視点は、権威主義体制の比較分析だけの道具ではない。手続き的正統性という強力だが万能ではない装置を持つ民主主義国もまた、業績・イデオロギー・カリスマ・歴史という同じ四つの源泉のあいだで、常に綱渡りを続けている。
近年の政治的分極化やポピュリズムの高まりは、この綱渡りが不安定化した徴候として理解することができる。民主主義国に生きる私たちが直面しているのは、権威主義体制とは無縁の特殊な危機ではなく、あらゆる政治体制が抱える普遍的な問い - 正統性をどこに立脚させるか - が、選挙という装置の陰から表舞台に姿を現しつつある局面なのかもしれない。
